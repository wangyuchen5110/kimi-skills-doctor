# Changelog

## 0.1.0

- Initial Kimi Code plugin: the `skills-doctor` skill, `/kimi-skills-doctor:check`,
  `:plan` and `:fix` slash commands, and a `skills-doctor` MCP server declaration
  (pinned to `opencode-skills-doctor@0.9.4`). Works in the Kimi Code CLI and the
  desktop app, which share `~/.kimi-code/`.
